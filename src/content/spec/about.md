## 在折腾什么

- **TheDemiuge** —— 一个 Agent 驱动的 RPG。UE5.8 + C++ 搓游戏本体，Go 那边写了 AI 通信桥（ReAct / MCP / SSE，已经跑通）。本体按 L0~L10 分层，现在啃到 L0 的时间系统。

  说真的，最早我想做的是「游戏 ↔ 大模型」那层通信框架，后来发现本体不搭扎实，Agent 接进来也没地方落脚。所以现在的重心全压在游戏本体的架构上。模型端那套端侧蒸馏我判断过之后砍了——玩家机器不可控，复杂度还会把真正难的部分挤走。

- **算法竞赛** —— NOIP 2023 省一、ACM 省银。省赛打得不算好，运气和队友各占一半。题解和踩的坑都写在这个博客里。
